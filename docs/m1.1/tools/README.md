# M1.1 tools (documentation copies)

These are copies of the scripts M1.1 uses. The paths in them are placeholders for your own layout; set them before
running anything:

| Placeholder | Stands for |
|---|---|
| `<research>` | the research folder: the llama.cpp fork in `<research>\llama.cpp`, its builds, these tools, run outputs |
| `<models>` | where the GGUF model files live |
| `<baseline>` | the M0 baseline folder (its `tools\reslog.ps1` resource sampler; not in this repo) |
| `<maya-build>` | the Project Maya build folder; its `env\Library` supplied the CUDA toolkit |
| `<vs-buildtools>` | the Visual Studio Build Tools install folder |
