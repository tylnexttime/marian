# M1.0 tools (documentation copies)

These are copies of the scripts the M1.0 runs used. The paths in them are placeholders for your own layout; set them
before running anything:

| Placeholder | Stands for |
|---|---|
| `<research>` | the research folder: the llama.cpp fork in `<research>\llama.cpp`, its build, these tools, run outputs |
| `<models>` | where the GGUF model files live |
| `<baseline>` | the M0 baseline folder (its `build.bat` and the `tools\reslog.ps1` resource sampler; not in this repo) |
| `<maya-build>` | the Project Maya build folder; its `env\Library` supplied the CUDA toolkit |
| `<vs-buildtools>` | the Visual Studio Build Tools install folder |
| `<system-ssd>`, `<data-ssd>` | the two drives `maya_cve.ps1` compares (C: and E: on the reference laptop) |
